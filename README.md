# 🐾 Petivolution

生态模拟沙盒游戏 - 观察动物行为、调整生态平衡

## ✨ 核心玩法

**投放动物** → **观察行为** → **发现问题** → **环境干预** → **生态稳定**

- 🐱 **猫**：捕食者，通过捕猎老鼠获取食物
- 🐭 **鼠**：食腐者，在垃圾堆中觅食

## 🎯 V1 验收标准

| 标准 | 描述 |
|------|------|
| **稳定性** | 10只鼠 + 2只猫，持续运行≥5分钟不崩溃 |
| **可解释性** | 点选动物可见：当前状态、原因、需求值 |
| **干预有效** | 放置水源/灌木/垃圾点能明显改变种群走向 |
| **性能** | 200-300个实体不掉帧 |

## 🛠️ 技术栈

- **前端框架**: React + TypeScript + Vite
- **游戏引擎**: Phaser 3
- **状态管理**: Zustand
- **模拟层**: Web Worker (独立线程)
- **存档**: IndexedDB

## 📁 项目结构

```
src/
├── app/         # React UI (面板、工具栏)
├── game/        # Phaser 场景和渲染
├── sim/         # 纯逻辑模拟层 (AI、生态)
├── worker/      # Web Worker 入口
├── storage/     # IndexedDB 存档
└── shared/      # 共享类型和配置
```

| 对象 | 图标 | 作用 |
|------|------|------|
| 水源 | 💧 | 动物喝水恢复"口渴"值 |

## 🧠 AI 系统

动物使用 **Utility AI** 决策系统：

1. 评估各种需求（饥饿、口渴、疲劳、威胁）
2. 计算每个行动的效用分数
3. 选择得分最高的行动执行

### 行为状态

| 状态 | 描述 |
|------|------|
| Idle | 发呆，无事可做 |
| Wander | 闲逛探索 |
| Chase | 追逐猎物（猫） |
| Flee | 逃离威胁（鼠） |
| Eat | 进食 |
| Drink | 喝水 |
| Sleep | 休息恢复疲劳 |
